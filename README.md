# Sprint 2 - Frontend Mobile

Aplicativo mobile desenvolvido em React Native com Expo para gerenciamento de sensores industriais.

## Funcionalidades

- Listagem de sensores
- Cadastro de sensores
- Visualização de detalhes

## Tecnologias

- React Native
- Expo
- TypeScript
- React Navigation

## Dados

Os dados são simulados através de um mock local, sem integração com backend.

## Executar

npm install

npx expo start
